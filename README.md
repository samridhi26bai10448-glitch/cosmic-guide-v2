# 🌌 Cosmic Guide — Smart Skywatching Assistant

A beginner-friendly astronomy website that helps users explore the night sky, understand Moon phases, check planet rise and set times, and discover constellations.

🔗 **Live Demo:** https://samridhi26bai10448-glitch.github.io/cosmic-guide-v2/

## ✨ Features

- 🌙 **Moon Phases:** Explore the current estimated Moon phase and illumination.
- 🪐 **Planet Information:** View rise and set times for Mercury, Venus, Mars, Jupiter, and Saturn.
- ☁️ **Sky Conditions:** Check local weather information and cloud cover.
- 📍 **City Search:** Explore sky conditions for a selected city.
- ✨ **Constellation Guide:** Learn about constellations visible in the night sky.
- 🔭 **Interactive Sky Map:** Explore the sky through an interactive map.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Astronomy Engine

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/samridhi26bai10448-glitch/cosmic-guide-v2.git
   ```

2. Open the project folder:

   ```bash
   cd cosmic-guide-v2
   ```

3. Start a local server:

   ```bash
   python -m http.server 8000
   ```

4. Open http://localhost:8000 in your browser.
